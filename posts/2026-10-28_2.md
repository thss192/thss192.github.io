## 前置状态确认

~~~bash
# 查看当前分支和文件状态
git status

# 查看远程仓库地址（应该能看到 origin）
git remote -v

# 查看提交历史（简洁一行一条）
git log --oneline
~~~

## 一、查看与对比类指令

### 1. 看工作区和暂存区的差异

~~~bash
# 查看还没 git add 的改动
git diff

# 查看已经 git add、还没 commit 的改动
git diff --staged
~~~

### 2. 看某个文件的历史

~~~bash
# 看某个文件每一行是谁、哪次提交改的
git blame main.py

# 看某个文件的提交历史
git log --oneline -- main.py
~~~

### 3. 看提交的详细内容

~~~bash
# 看最近一次提交改了什么
git show

# 看指定提交（把 abc1234 换成 git log 里看到的短哈希）
git show abc1234
~~~

## 二、撤销与回退类指令

### 1. 工作区改坏了，还没 add —— 丢弃改动

~~~bash
# 丢弃某个文件的修改，恢复到上次提交的样子
git restore main.py

# 丢弃所有工作区改动（危险，确认后再敲）
git restore .
~~~

### 2. 已经 add 了，想撤回暂存区

~~~bash
# 把文件从暂存区拿出来，但保留工作区改动
git restore --staged main.py
~~~

### 3. 已经 commit 了，想撤销这次提交但保留改动

~~~bash
# 撤销最近一次提交，改动回到工作区（--soft 保留在暂存区）
git reset --soft HEAD~1

# 撤销最近一次提交，改动回到工作区但不在暂存区（推荐练习用这个）
git reset HEAD~1
~~~

### 4. 提交信息写错了

~~~bash
# 修改最近一次提交的说明（还没 push 时用）
git commit --amend -m "fix: 修正提交说明"
~~~

## 三、分支类指令

### 1. 创建与切换分支

~~~bash
# 创建并切换到新分支
git switch -c feature/log-improve

# 查看所有分支（当前分支前面有 *）
git branch
~~~

### 2. 在新分支上提交

~~~bash
# 改点东西，比如给 client.py 加一行注释
git add client.py
git commit -m "feat: 日志增加注释"
~~~

### 3. 切回 main 并合并

~~~bash
# 切回主分支
git switch main

# 把 feature 分支合并进来
git merge feature/log-improve
~~~

### 4. 删除已合并的分支

~~~bash
git branch -d feature/log-improve
~~~

### 5. 制造并解决一次冲突

~~~bash
# 在 main 上改 main.py 第一行并提交
git switch main
# 手动改 main.py，比如改提示语
git add main.py
git commit -m "chore: main 分支改提示语"

# 新建分支，改同一行并提交
git switch -c conflict-test
# 手动改 main.py 同一行
git add main.py
git commit -m "chore: 分支改提示语"

# 切回 main 合并，触发冲突
git switch main
git merge conflict-test
~~~
冲突后打开 `main.py`，会看到：

~~~text
<<<<<<< HEAD
你改的内容
=======
分支改的内容
>>>>>>> conflict-test
~~~

手动保留想要的内容、删掉这些标记，然后：

~~~bash
git add main.py
git commit -m "merge: 解决冲突"
git branch -d conflict-test
~~~

## 四、远程协作类指令

### 1. 推送分支

~~~bash
# 把当前分支推到远程
git push

# 第一次推新分支时指定上游
git push -u origin feature/log-improve
~~~

### 2. 拉取远程更新

~~~bash
# 拉取并合并远程 main
git pull

# 只想看远程有什么变化，不合并
git fetch
git log --oneline origin/main
~~~

### 3. 查看远程分支

~~~bash
git branch -r
~~~

## 五、暂存工作现场（stash）

写代码写到一半要切分支修 bug 时很有用：

~~~bash
# 把当前没提交的改动藏起来
git stash

# 看藏了哪些
git stash list

# 恢复最近一次 stash（并删除这条 stash 记录）
git stash pop

# 只恢复不删除
git stash apply
~~~

## 六、给项目补上规范

### 1. 补充 `.gitignore` 的验证

~~~bash
# 确认 .env 没被追踪（应该没有任何输出）
git ls-files | findstr .env
~~~

### 2. 查看哪些文件被追踪

~~~bash
git ls-files
~~~
