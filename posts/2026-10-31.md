## 一、登录设置
### 关闭密码登录
我习惯于密钥登录(也是为了防范密码被猜到或者暴力破解)，因此我第一步拿到手，我会关闭密码登录。
~~~ bash
# 查看是否允许密码登录
sshd -T | grep passwordauthentication
# 预期输出 passwordauthentication yes/no
# 如果是yes，修改文件末的passwordauthentication yes，改为no
vi /etc/ssh/sshd_config
# 查看 /etc/ssh/sshd_config.d/ 下的子文件
grep -r PasswordAuthentication /etc/ssh/sshd_config.d/
# 如出现：/etc/ssh/sshd_config.d/50-cloud-init.conf:PasswordAuthentication yes
# 修改子文件
vi /etc/ssh/sshd_config.d/50-cloud-init.conf
# 检验语法
sshd -t
# 重启服务
systemctl restart ssh
~~~
### 配置密钥登录
~~~ bash
# 查看是否有密钥
cat ~/.ssh/authorized_keys
# 配置公钥
echo "你的公钥" > ~/.ssh/authorized_keys
# 配置文件权限
chmod 700 ~/.ssh
chmod 600 ~/.ssh/authorized_keys
# 新开一个终端窗口，用密钥测试能否登录
ssh -i 私钥路径 root@IP
~~~
其他用户则在用户根目录做同样操作即可

## 二、重命名主机名

~~~ bash
# 例如：将主机名命名为dev01
hostnamectl set-hostname dev01
# 修改 hosts 文件
vi /etc/hosts
# 修改对应行为 127.0.1.1 localhost.localdomain dev01
# 输入验证
hostname
~~~

## 三、配置 Swap 虚拟内存
1. 创建 2GB 的 Swap 文件（可能需要几秒钟）
~~~bash
fallocate -l 2G /swapfile
~~~
2. 设置只有 root 能读写（极其重要，保证安全）
~~~bash
chmod 600 /swapfile
~~~
3. 将文件格式化为 Swap 格式
~~~bash
mkswap /swapfile
~~~
(这一步会输出类似 Setting up swapspace version 1, size = 2 GiB 的提示)

4. 启用 Swap
~~~bash
swapon /swapfile
~~~
5. 设置开机自动挂载
如果不做这一步，重启后 Swap 就失效了。
~~~bash
echo '/swapfile none swap sw 0 0' | tee -a /etc/fstab
~~~
6. 验证是否成功
输入：
~~~bash
free -h
~~~
能在 Swap 那一行看到 2.0Gi，就算成功了。

## 四、开启防火墙（UFW）

1. 检查防火墙当前状态
~~~bash
ufw status
~~~
(预期输出应该是 Status: inactive，说明目前没开)

2. 放行 SSH 端口（生死攸关的一步！）
~~~bash
ufw allow 22/tcp
~~~
3. 开启防火墙
~~~bash
ufw enable
~~~
(系统会提示 Command may disrupt existing ssh connections. Proceed with operation (y|n)?，输入 y 然后回车)

4. 验证状态
~~~bash
ufw status verbose
~~~
这个时候，你应该能看到 Status: active，并且列表里有一条 22/tcp ALLOW IN Anywhere。
