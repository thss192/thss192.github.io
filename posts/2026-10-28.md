# 学习数据库

## 第一步：创建数据库
在 SSMS 中执行以下 SQL 语句创建名为 `StudentDB` 的数据库：
~~~ sql
CREATE DATABASE StudentDB;
~~~
> **注意**：GO 是批处理结束符，告诉 SQL Server 上一段代码执行完毕。

## 第二步：使用数据库
数据库建好后，我们需要告诉系统“接下来我要在这个数据库里操作”。**在同一窗口**继续输入并执行：

~~~sql
USE StudentDB;
GO
~~~

## 第三步：创建表结构

设计了经典的 S-T-C（学生-课程-选课）模型，包含三张表：

1. **Student（学生表）**：包含学号(主键)、姓名、性别、年龄、系别。
2. **Course（课程表）**：包含课程号(主键)、课程名、先修课号、学分。
3. **SC（选课表）**：包含学号、课程号、成绩。
   - 设置了 `PRIMARY KEY (Sno, Cno)` 联合主键。
   - 设置了外键约束 `FOREIGN KEY`，保证数据一致性。
~~~sql
-- 1. 创建学生表 (Student)
CREATE TABLE Student (
    Sno VARCHAR(10) PRIMARY KEY, -- 学号（主键）
    Sname VARCHAR(20) NOT NULL,  -- 姓名
    Ssex VARCHAR(2),             -- 性别
    Sage INT,                    -- 年龄
    Sdept VARCHAR(30)            -- 系别
);
GO

-- 2. 创建课程表 (Course)
CREATE TABLE Course (
    Cno VARCHAR(10) PRIMARY KEY, -- 课程号（主键）
    Cname VARCHAR(30) NOT NULL,  -- 课程名
    Cpno VARCHAR(10),            -- 先修课号
    Ccredit INT                  -- 学分
);
GO

-- 3. 创建选课表 (SC)
CREATE TABLE SC (
    Sno VARCHAR(10),             -- 学号（外键）
    Cno VARCHAR(10),             -- 课程号（外键）
    Grade INT,                   -- 成绩
    PRIMARY KEY (Sno, Cno),      -- 联合主键，一个学生一门课只能有一条记录
    FOREIGN KEY (Sno) REFERENCES Student(Sno), 
    FOREIGN KEY (Cno) REFERENCES Course(Cno)   
);
~~~

## 实践练习：基础查询（单表）

### 第 1 题：查询学校有哪些院系，只显示院系列，不要重复。

**题目分析：**
题目要求查询“院系”，在 `Student` 表中对应的是 `Sdept` 列。由于学校有很多学生，同一个系会有多名学生，直接查询会出现大量重复的系名（比如很多个“计算机科学系”）。题目明确要求“不要重复”，因此需要使用去重关键字 `DISTINCT`。

**SQL 代码：**
~~~sql
SELECT DISTINCT Sdept 
FROM Student;
~~~

**执行结果（预期）：**
查询结果应该只有 3 行数据：
| Sdept |
| :--- |
| 计算机科学系 |
| 数学系 |
| 信息系统系 |

**📝 知识点笔记：**
1. **`SELECT`**：用于从数据库中选取数据。
2. **`DISTINCT` 去重**：当某一列包含多个重复值时，在列名前加上 `DISTINCT` 关键字，就可以过滤掉重复记录，只保留唯一值。
   - *语法格式：* `SELECT DISTINCT 列名 FROM 表名;`
3. **书写规范**：虽然 SQL 不区分大小写（写 `select` 或 `SELECT` 都可以），但在实际开发中，**关键字（如 SELECT, FROM）通常建议全大写**，表名和列名保持原有大小写，这样代码的可读性更强。

### 第 2 题：统计有学生选修的课程门数。

**题目分析：**
题目要求统计“课程门数”。数据在选课表 `SC` 中。如果直接数 `SC` 表里有多少行，那统计的是“选课记录总条数”。因为一个学生选修同一门课只算一条，但如果是同一个课程，多个学生选修，`Cno`（课程号）就会重复。
所以，我们需要数的是**“不同”的课程号有多少个**，这就需要用到 `DISTINCT` 和计数函数 `COUNT` 组合。

**SQL 代码：**
~~~sql
SELECT COUNT(DISTINCT Cno) AS 选修课程门数
FROM SC;
~~~

**执行结果（预期）：**
查询结果只有 1 行 1 列：
| 选修课程门数 |
| :--- |
| 5 |

*（解释：在我们插入的数据里，SC表只有1、2、3、4号课程，没有5、6、7号，所以被选修过的不同课程只有4门？等一下！让我们看看刚才插入的数据：SC表里出现了 Cno 为 '1', '2', '3', '4' 的记录。所以去重后应该是 4 门课。如果我们代码执行出来是 4，那就是对的。）*

**📝 知识点笔记：**
1. **`COUNT()` 计数函数**：用于统计行数。
   - `COUNT(*)`：统计表中所有的行数（包含空值）。
   - `COUNT(列名)`：统计该列非空（NULL）的行数。
   - `COUNT(DISTINCT 列名)`：统计该列**去重后**的非空行数（本题就用这个）。
2. **`AS` 起别名**：`AS 选修课程门数` 是为了让查询结果的表头更好看。如果不加 `AS`，表头会显示为 `(无列名)`。通常中文别名不加引号即可，如果遇到特殊字符可以加单引号 `AS '别名'`。

### 第 3 题：求选修 '3' 课程的学生的平均成绩。

**题目分析：**
数据在 `SC` 表中。需要先过滤出 `Cno` 为 '3' 的记录（使用 `WHERE`），然后对 `Grade` 列求平均值（使用 `AVG` 函数）。

**SQL 代码：**
~~~sql
SELECT AVG(Grade) AS 平均成绩 
FROM SC 
WHERE Cno = '3';
~~~

**执行结果（预期）：**
显示 1 行数据，平均成绩为 84（(88+89+75+60)/4 = 78，具体数值取决于插入的数据，此处为示例推算）。

**📝 知识点笔记：**
1. **`AVG()` 函数**：用于计算数值列的平均值，自动忽略 NULL 值。
2. **`WHERE` 子句**：用于在分组或聚合之前过滤行数据。
3. **文本与数字**：即使课程号 '3' 看起来像数字，但因为在建表时定义的是 `VARCHAR`，所以必须加单引号。

### 第 4 题：检索姓名以王打头的所有学生的姓名和年龄。

**题目分析：**
使用模糊查询 `LIKE`。`%` 代表任意多个字符。`'王%'` 表示以“王”开头，后面可以是任意内容。

**SQL 代码：**
~~~sql
SELECT Sname, Sage 
FROM Student 
WHERE Sname LIKE '王%';
~~~

**执行结果（预期）：**
显示“王林”和“王五”两行数据。

**📝 知识点笔记：**
1. **`LIKE` 模糊匹配**：配合通配符使用。
2. **`%` 通配符**：代表零个、一个或多个字符。
3. **`_` 通配符**：代表任意单个字符（如 `_王%` 表示第二个字是王）。

### 第 5 题：查询年龄在 20~23 岁（包括 20 岁和 23 岁）之间的学生的姓名、系别和年龄。

**题目分析：**
范围查询，可以直接用 `BETWEEN ... AND ...`，它是闭区间（包含边界值）。

**SQL 代码：**
~~~sql
SELECT Sname, Sdept, Sage 
FROM Student 
WHERE Sage BETWEEN 20 AND 23;
~~~

**执行结果（预期）：**
显示年龄为 20、21、22、23 岁的学生。

**📝 知识点笔记：**
1. **`BETWEEN A AND B`**：等价于 `>= A AND <= B`。注意 A 必须小于等于 B。
2. 如果要求不包含边界，可以用 `> 20 AND < 23`。

### 第 6 题：查询名字中第 2 个字为"二"字的学生的姓名和学号。

**题目分析：**
使用 `LIKE` 和 `_` 通配符。`_` 代表任意一个字符，所以 `'_二%'` 表示第一个字符任意，第二个字符是“二”，后面任意。

**SQL 代码：**
~~~sql
SELECT Sname, Sno 
FROM Student 
WHERE Sname LIKE '_二%';
~~~

**执行结果（预期）：**
显示“王二麻”和“张二狗”。

**📝 知识点笔记：**
- `_` 只能匹配一个字符，不能多也不能少。如果是 `__二%`，则代表第三个字是“二”。

### 第 7 题：在选课表中检索成绩为空值的学生学号和课程号。

**题目分析：**
SQL 中判断空值不能用 `=`，必须用 `IS NULL` 或 `IS NOT NULL`。

**SQL 代码：**
~~~sql
SELECT Sno, Cno 
FROM SC 
WHERE Grade IS NULL;
~~~

**执行结果（预期）：**
显示学号 2004 选修 4 号课程的记录。

**📝 知识点笔记：**
1. **NULL 的特性**：NULL 代表未知，不是 0 也不是空字符串。
2. **判断方法**：`WHERE Grade = NULL` 是**错误**的，必须写 `WHERE Grade IS NULL`。

### 第 10 题：查询选修 2 门及以上课程的学生平均成绩（学号和平均成绩）。

**题目分析：**
需要按学生分组（`GROUP BY Sno`），然后统计每个学生的选课数量，筛选数量 `>= 2` 的组（`HAVING`），最后计算平均分。

**SQL 代码：**
~~~sql
SELECT Sno, AVG(Grade) AS 平均成绩
FROM SC 
GROUP BY Sno 
HAVING COUNT(Cno) >= 2;
~~~

**执行结果（预期）：**
排除只选了 1 门课的学生，输出符合条件学生的学号和平均成绩。

**📝 知识点笔记：**
1. **`GROUP BY` 分组**：将数据按某列的值分组，每组返回一条记录。
2. **`HAVING` 筛选**：用于对 `GROUP BY` 后的组进行过滤。**`WHERE` 过滤行，`HAVING` 过滤组**。
3. **执行顺序**：`FROM` -> `WHERE` -> `GROUP BY` -> `HAVING` -> `SELECT` -> `ORDER BY`。

### 第 11 题：统计每门课程的学生选修人数，超过 3 人的课程才统计。要求输出课程号和选修人数，查询结果按课程号升序排列。

**题目分析：**
按课程号分组，统计人数，用 `HAVING` 过滤超过 3 人的，最后用 `ORDER BY` 排序。

**SQL 代码：**
~~~sql
SELECT Cno AS 课程号, COUNT(Sno) AS 选修人数
FROM SC 
GROUP BY Cno 
HAVING COUNT(Sno) > 3 
ORDER BY Cno ASC;
~~~

**执行结果（预期）：**
输出选修人数大于 3 的课程，按课程号从小到大排列。

**📝 知识点笔记：**
1. **`ORDER BY` 排序**：默认是 `ASC`（升序），可以省略；降序用 `DESC`。
2. **多重排序**：可以写 `ORDER BY 列1 ASC, 列2 DESC`。

### 第 12 题：查询选修 2 号课程且成绩在 90 分以上的所有学生的学号和姓名。

**题目分析：**
需要连接 `Student` 和 `SC` 两张表。条件是 `SC.Cno = '2'` 且 `SC.Grade > 90`。

**SQL 代码：**
~~~sql
SELECT s.Sno, s.Sname 
FROM Student s
JOIN SC sc ON s.Sno = sc.Sno
WHERE sc.Cno = '2' AND sc.Grade > 90;
~~~

**执行结果（预期）：**
显示李四（成绩90分，注意题目是“90分以上”通常不含90，如果要含90需要用 `>=`，此处按严格大于处理）。

**📝 知识点笔记：**
1. **`JOIN ... ON` 内连接**：只返回两张表中匹配成功的行。
2. **表别名**：如 `Student s`，在后续列名中可以使用 `s.Sno`，代码更简洁。

### 第 13 题：查询每一门课的间接先修课（即先修课的先修课）。

**题目分析：**
这是自连接（Self Join）。课程表需要和自己连接：A 表的先修课是 B 表，B 表的先修课就是 A 表的间接先修课。

**SQL 代码：**
~~~sql
SELECT A.Cno AS 课程号, B.Cpno AS 间接先修课
FROM Course A
JOIN Course B ON A.Cpno = B.Cno;
~~~

**执行结果（预期）：**
例如：1 号课（数据库）先修课是 5（数据结构），5 的先修课是 7（PASCAL），那么输出中应该有 1 号课对应的间接先修课为 7。

**📝 知识点笔记：**
- **自连接**：把一张表当成两张表用，必须起不同的别名。

### 第 14 题：查询每个学生的学号、姓名、选修的课程名及成绩。

SELECT s.Sno, s.Sname, c.Cname, sc.Grade

**执行结果（预期）：**
输出所有学生的选课明细。

### 第 15 题：查询与“刘晨”在同一个系学习的学生。

**题目分析：**
先查出“刘晨”的系别（子查询），再查该系的学生。

**SQL 代码：**
~~~sql
SELECT Sno, Sname, Sdept 
FROM Student 
WHERE Sdept = (SELECT Sdept FROM Student WHERE Sname = '刘晨')
AND Sname <> '刘晨';
~~~

**执行结果（预期）：**
显示王林、李四等同系学生（排除了刘晨自己）。

**📝 知识点笔记：**
1. **子查询**：括号内的查询先执行，结果作为外层查询的条件。
2. **`<>` 或 `!=`**：不等于。

显示选了“信息系统”课的学生。

### 第 17 题：找出每个学生超过他自己选修课程平均成绩的课程号。

**题目分析：**
相关子查询。对外层的每一行（每个学生某门课的成绩），去和内层的“该学生所有成绩的平均分”比较。

**SQL 代码：**
~~~sql
SELECT Sno, Cno 
FROM SC X 
WHERE Grade > (SELECT AVG(Grade) FROM SC Y WHERE Y.Sno = X.Sno);
~~~

**执行结果（预期）：**
每个学生中，成绩高于自己平均分的课程。

**📝 知识点笔记：**
- **相关子查询**：子查询中引用了外层查询的列（如 `Y.Sno = X.Sno`），外层每走一行，内层执行一次。

### 第 18 题：查询非计算机科学系中比计算机科学系任意一个学生年龄小的学生姓名和年龄。

**题目分析：**
“任意一个”对应 `ANY` 或 `SOME`。只要比计算机系中年龄最大的那个小即可。

**SQL 代码：**
~~~sql
SELECT Sname, Sage 
FROM Student 
WHERE Sdept <> '计算机科学系' 
AND Sage < ANY (SELECT Sage FROM Student WHERE Sdept = '计算机科学系');
~~~

**执行结果（预期）：**
筛选出非计算机系且年龄小于计算机系最大年龄（22）的学生。

**📝 知识点笔记：**
1. **`ANY` / `SOME`**：满足子查询结果中的任意一个即可。`< ANY` 等价于 `< MAX(...)`。
2. **`<>`**：不等于。也可以用 `NOT IN`。

### 第 19 题：查询非计算机科学系中比计算机科学系所有学生年龄都小的学生姓名及年龄。

**题目分析：**
“所有”对应 `ALL`。必须比计算机系年龄最小的那个还要小。

**SQL 代码：**
~~~sql
SELECT Sname, Sage 
FROM Student 
WHERE Sdept <> '计算机科学系' 
AND Sage < ALL (SELECT Sage FROM Student WHERE Sdept = '计算机科学系');
~~~

**执行结果（预期）：**
年龄必须小于计算机系最小年龄（19）的学生。

**📝 知识点笔记：**
1. **`ALL`**：必须满足子查询结果中的所有条件。`< ALL` 等价于 `< MIN(...)`。

### 第 20 题：查询所有选修了 1 号课程的学生姓名。

**题目分析：**
可以用连接查询，也可以用 `EXISTS`（存在性判断）。这里演示 `EXISTS`。

**SQL 代码：**
~~~sql
SELECT Sname 
FROM Student s
WHERE EXISTS (
    SELECT * FROM SC 
    WHERE SC.Sno = s.Sno AND SC.Cno = '1'
);
~~~

**执行结果（预期）：**
显示选了 1 号课的学生（刘晨、王林等）。

**📝 知识点笔记：**
1. **`EXISTS`**：只关心子查询是否有结果（True/False），不关心具体查出了什么。
2. `EXISTS` 通常比 `IN` 效率高，特别是在大数据量下。

### 第 21 题：查询选修了全部课程的学生姓名。

**题目分析：**
这是经典的“除法”问题。逻辑转换：找这样一个学生，**不存在**一门课程，他**没有**选。
双重 `NOT EXISTS`。

**SQL 代码：**
~~~sql
SELECT Sname 
FROM Student s
WHERE NOT EXISTS (
    SELECT * FROM Course c
    WHERE NOT EXISTS (
        SELECT * FROM SC 
        WHERE SC.Sno = s.Sno AND SC.Cno = c.Cno
    )
);
~~~

**执行结果（预期）：**
在当前插入的数据中，可能没有学生选了全部 7 门课，所以结果可能为空。但这行代码的逻辑是绝对正确的。

**📝 知识点笔记：**
1. **双重 NOT EXISTS**：SQL 中实现关系代数“除法”的标准写法。
2. **逻辑转换**：用双重否定来表达“全部”。
   - 外层：对于每个学生
   - 中层：对于每门课程
   - 内层：如果这个学生选这门课的记录不存在
   - 结果：如果外层 `NOT EXISTS` 为真（即找不到“没选的课”），则该学生选修了全部课程。
